¿Para que sirve NetIot Guardian?

Administra y gestiona todos tus dispositivos IoT y Domotica al alcance de tus manos.

Fabricantes

Integramos acceso a APIs privadas para el control de más 8 fabricantes de dispositivos IoT.

APIs Abierta

Contamos con API abierta, para controlar proyectos personales de domotica.

¿Como trabajamos?

Ultilizamos tecnologias de backend "Springboot", añadiendo seguridad estandar con "Spring Segurity" y "JWT". Además integramos tecnologias en "Python" para el cliente, lo que nos permite establecer una conexion con el backend permitiendo ejecutar acciones desde el servidor hacia la red local del cliente.

Preguntas frecuentes

¿Tiene algun costo?

¡En lo absoluto! El software NetIoT Guardian, es completamente opensource (Codigo Abierto). Cualquier individuo o entidad puede usarlo libremente.

¿Mis datos estan seguros?

El nivel de seguridad depende totalmente de la configuracion de despliegue del aplicativo en la infrastructura de la persona o entidad, lo recomendable es configurar un entorno seguro para la base de datos y el servidor.
